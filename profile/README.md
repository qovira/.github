# Qovira

**Your assistant. Yours alone.**

Qovira is a private, self-hostable personal assistant — reminders, notes, calendar, and quick answers, organized by AI that runs on a server you own and a model you choose.

It's still being built. For the story so far, see [qovira.ai](https://qovira.ai).

The code lives here too: the app, [`qovira`](https://github.com/qovira/qovira), and the open foundation it's built on — [`@qovira/theme`](https://github.com/qovira/theme) (design tokens, fonts, and theming runtime) and [`@qovira/ui`](https://github.com/qovira/ui), its Svelte component library.
